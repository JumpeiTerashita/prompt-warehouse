# prompt-warehouse

プロンプト倉庫: ComfyUI / A1111 の生成画像からプロンプトを自動登録する単一HTMLアプリ。

- 公開ページ: https://jumpeiterashita.github.io/prompt-warehouse/
- データの保存先はアプリ内で切り替えられます（このブラウザの IndexedDB / Google ドライブ）。
  画像や登録データは GitHub には保存されません。

## Phase 1 改善（2026-11-11、スマホ閲覧優先）

- 品質タグ除外を既定ONにし、設定を端末に保存
- カード／詳細のタグ・LoRAピルをクリックで絞り込み・検索可能に
- 検索対象に seed / LoRA / サンプラー / サイズ / 登録日を追加し、入力にデバウンスを導入
- ソートに「お気に入り優先」「ランダム」を追加
- サムネイル表示の切替（トリミング／全体表示）
- 検索・絞り込み・詳細の状態を URL ハッシュに保存（カードへの直リンク対応）
- 削除に「元に戻す」、詳細の未保存編集に警告を追加
- カードのキーボード操作、サムネイルの遅延読み込み、スマホ向けレイアウト調整（タグ自動折りたたみ、タップ領域拡大、入力時ズーム防止）

## Phase 1.5 監査修正（2026-11-11）

- select の iOS 自動ズーム対策（モバイルで16px化）
- ビューアのカルーセル移動を短縮（1コマ 370ms → 240ms、上限 520ms → 400ms）
- 余白の半端値（3/5/7/9/11px）を全て偶数へ丸めた（設計リズム側は Phase 2 のトークン判断へ温存）
- viewport-fit=cover を付け、サイドバー／ビューア上部／詳細ヘッダにセーフエリア上端対応を追加（Phase 1 の下端対応がこれで有効になる）
- theme-color をテーマ切替に連動、モバイルのピルを 32px 高に、取り込みプログレスバーを transform（scaleX）アニメーションへ変更

## スワイプ滑らかさ修正（2026-11-11、実機動画フィードバック）

- 拡大表示で「サムネイル取得済み・原寸未取得」の画像に来ると原寸を取りに行かず低解像度のまま固まる不具合を修正（showProgressive の早期リターン）。縮小版は同じフレームで即表示し、原寸は必ず裏で取得して差し替える
- 拡大表示の先読みを拡張：前後1枚は原寸＋縮小版、前後2枚は縮小版まで温める
- カルーセルのスライドは IntersectionObserver 待ちをやめて即時取得（スワイプ中の灰色スライド解消）
- 中央スライドの原寸アップグレードは、スワイプが止まって約140ms経ってから開始（通過するだけのスライドの原寸ダウンロードがサムネイルと競合しないように）

## Phase 2（2026-11-11）

- 余白をデザイントークン化（--sp-0〜6、2px刻みリズムを明文化。計算値は不変）。サイドボタンの文言も短縮
- セット（取り込み単位）: 取り込み時に batchId を自動付与。既存分は登録時刻の30分間隔で推定グルーピング（索引には書き戻さない）。サイドバーで絞り込み、セットバーからカルーセル表示へ。並び替え「ランダム」との併用でセット内シャッフル再生
- キャラ自動判定: 既知テンプレートとの照合（名前トークン＋特徴トークンのスコア）。取り込み時に付与し、既存分は同じ辞書で都度判定。サイドバー絞り込み、カードのバッジ、詳細表示
- 一括編集: 複数選択モードで、お気に入り一括付け外し、タグ追加、セット移動（新規作成含む）、一括削除（Undo はまとめて復元）
- 検索式: `-ワード` で除外、`OR` でいずれかのグループに一致
- 重複フィルタ: 同一プロンプト＋同一モデル（seed違い含む）を検出して絞り込み
- 全タグブラウザ: 全タグをカテゴリ別（品質／人数／髪／目／衣装／場所／表情・ポーズ／その他）に一覧し、その場で絞り込み

## Phase 3（2026-11-11）

- ブロック分解: 詳細でポジティブプロンプトを キャラ／人数・主体／髪／目／衣装／表情・ポーズ／場所・背景／品質／LoRA／その他 に自動分類して表示。ブロック単位コピー、トークンクリックで検索
- 2件比較: 一括編集モードで2件選んで「2件を比較」。生成情報の差分行ハイライト＋トークンの Aのみ／Bのみ／共通 を色分け
- 似たプロンプト: 詳細に類似度つきで最大8件（自動タグの Jaccard ＋ LoRA 一致ボーナス）
- MuseCon連携: 詳細から「再生成（同じ条件）」「バリエーション（別seed）」。接続先とAPIキーはサイドバーで設定し、この端末のブラウザ内にのみ保存。生成結果はそのまま倉庫に取り込まれる。キー未設定時は「再生成リクエストをコピー」でJSONだけ持ち出せる

## Phase 4（進行中）

- 索引の世代管理と競合検出: 索引に generation を持たせ、ページと直接登録ツールの両方が書き込みごとに進める。保存前に索引ファイルの md5 を照合し、読み込み後に他者（別タブ・直接登録）が更新していたら、黙って上書きせず確認を出す。60秒リフレッシュも md5 照合で済ませ、変わっていないときは索引本体（数MB）を落とさない
